rare-variants

This repository contains the scripts used for the analyses reported in the paper. Individual-level UK Biobank data are not included. The study used application 98032.

What is shared

  • Analysis scripts for the manuscript UK Biobank analyses. These require local UK Biobank files under data/.
  • Variant-level association results and other summary tables in summary/. These do not contain participant identifiers.
  • The simulation script and deposited simulation summaries. These can be run without UK Biobank access.

What is not shared

Genotypes, phenotypes, principal components, participant IDs, and matched-set membership files are omitted. See data/README.md for the files an approved UK Biobank user needs to place locally.

Install

conda env create -f env.yml
conda activate rare-variants

Simulation

Rscript simulation/revised_oracle_matching_simulation.R --calibrated --n-pcs=5 --n-iter=1000 --N=50000 --max-matched-cases=2500

A completed copy of this run is in summary/simulation/.

The R Markdown source for this overview is rare-variants.Rmd.
