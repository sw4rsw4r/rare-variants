Match cases to controls

Cases were matched to controls on PC1 through PC5 using Mahalanobis distance, without replacement. Sex and genotype were not used to construct the matches. The helper functions are in analysis/00_CLR/010_pc_matching_helpers.R.

source("analysis/00_CLR/010_pc_matching_helpers.R")

lambda_gc <- function(chisq) {
  median(as.numeric(chisq), na.rm = TRUE) / qchisq(0.5, 1)
}

method_cols <- c(
  "Unadjusted logistic" = "#D55E00",

p_map <- c(
  "Unadjusted logistic" = "P_PLAIN",
  "PC-adjusted logistic" = "P_PC_ADJUSTED",
  "CLR 1:6" = "P_1TO6",
  "CLR 1:4" = "P_1TO4",
  "CLR 1:1" = "P_1TO1"
)

qq_df <- function(data, panel) {
  out <- lapply(names(p_map), function(method) {
    p <- sort(as.numeric(data[[p_map[[method]]]]))
    p <- p[is.finite(p) & p > 0 & p <= 1]
    n <- length(p)
    data.frame(
      panel = panel,
      method = method,
      expected = -log10((seq_len(n) - 0.5) / n),
      observed = -log10(p),
      stringsAsFactors = FALSE
    )
  })
  d <- do.call(rbind, out)
  d$method <- factor(d$method, levels = names(method_cols))
  d
}

Simulation

The manuscript simulation used 1,000 replicates of 50,000 individuals and a common pool of 2,500 cases. Matched P values were score tests with the genotype coefficient set to zero.
